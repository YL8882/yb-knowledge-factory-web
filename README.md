# YB Knowledge Factory MVP

## 專案簡介

YB Knowledge Factory MVP 是一個 AI 學習工具。

使用者貼上 YouTube 網址後，系統自動完成：

YouTube URL
→ Transcript
→ Study Note
→ Markdown Output

本專案以 **Web First、MVP First、Workflow First** 為核心開發原則。

---

## 專案目標

建立一個可快速驗證市場的 Web MVP。

優先完成：

- YouTube 逐字稿
- AI Study Note
- Markdown 匯出

完成 MVP 後，再逐步擴充多語系、Mobile App、雲端同步等功能。
