# Recording Rules

以下情況必須更新 CHANGELOG：

- 新增正式文件
- 新增 Milestone
- 完成 Stage Gate
- 架構重大修改
- Workflow 重大修改
- Prompt 規格重大修改
- 發布新版本

以下情況不用更新：

- 錯字修正
- 排版調整
- 小幅內容補充
- 臨時測試
