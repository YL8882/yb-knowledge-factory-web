# Revenue Model v1.0

> 本文件定義 YB Learn 的營收模式（Revenue Model），作為產品商業化、訂閱制度、獲利策略與長期成長規劃的核心文件。

---

# 1. Purpose

本文件目的：

- 建立 YB Learn 營收模式
- 規劃產品獲利方式
- 建立長期可持續商業模式
- 作為 Pricing Strategy 的延伸
- 作為未來投資與產品規劃依據

---

# 2. Business Goal

YB Learn 不只是 AI 工具。

目標是建立：

> AI Learning Platform

讓使用者每天持續使用。

因此：

營收來自：

- 長期訂閱
- 高留存率
- 高續訂率

而不是一次性銷售。

# 7. Profitability Strategy

核心原則：

提高：

- 留存率
- 訂閱率
- 使用頻率

降低：

- API 成本
- 重複生成
- Output Tokens

讓：

每位使用者收入

>

每位使用者成本

# 13. Conclusion

YB Learn 採用以訂閱制為核心的 SaaS 營收模式。

短期目標是完成 Beta 驗證與建立第一批付費使用者；中期透過成本優化與產品迭代，提高留存率與轉換率；長期則逐步擴展至團隊、企業與 AI 知識服務，建立可持續成長的 AI Learning Platform。
