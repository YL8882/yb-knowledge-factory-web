# Go To Market Strategy v1.0

> 本文件定義 YB Learn 的 Go-To-Market（GTM）策略，規劃產品從 MVP、Beta 到正式上市的完整推廣、驗證與成長計畫。

---

# 1. Purpose

本文件目的：

- 規劃產品上市策略
- 驗證市場需求
- 建立第一批忠實使用者
- 驗證商業模式
- 建立產品成長流程

# 4. Customer Pain Points

目前市場問題：

- 收藏很多影片卻沒有真正學會
- 影片太長，沒有時間觀看
- 無法快速複習重點
- 筆記整理耗時
- 學習內容容易遺忘

---

# 5. Core Value Proposition

YB Learn 提供：

- 一鍵收藏影片
- 自動取得 Transcript
- AI 生成學習筆記
- Workflow 拆解
- Action List
- Review
- Knowledge Management

目標：

> 把「觀看影片」變成「真正學會」。

# 6. Launch Strategy

## Phase 1：Internal MVP

目標：

- 功能完成
- 成本驗證
- Bug 修正

使用者：

僅自己使用。

成功條件：

- 完整流程穩定
- 成本可接受

---

## Phase 2：Closed Beta

目標：

邀請少量使用者測試。

人數：

10～30 人。

收集：

- Bug
- 使用流程
- 功能需求
- 成本數據

---

## Phase 3：Open Beta

目標：

擴大測試。

人數：

100～500 人。

開始：

- Freemium
- Pro 訂閱

---

## Phase 4：Official Launch

正式推出：

- 官網
- Landing Page
- 收費方案
- 客服
- 教學文件

# 13. Conclusion

YB Learn 的 Go-To-Market 策略採用「先驗證、後擴張」的方式。

先以 MVP 驗證產品價值與成本模型，再透過 Closed Beta 收集真實使用數據，逐步導入 Freemium、訂閱制與正式商業化，降低風險並建立長期可持續的 AI 學習平台。
