# Sprint 01｜Home UI Design

## Objective

完成 YB Knowledge Factory MVP 首頁 UI，建立可操作的 MVP 介面。

本 Sprint 僅完成使用者介面（UI），不包含任何後端 API 或 AI 功能。

---

# Scope

包含：

- 首頁品牌設計
- 首頁版面配置
- UI 元件
- 色彩系統
- 響應式版面
- Google AI Studio Preview

不包含：

- YouTube API
- Transcript API
- Gemini
- Markdown Download

---
