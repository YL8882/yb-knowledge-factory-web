# Output Specification

## 1. Purpose

Define all output assets generated by YB Knowledge Factory.

This document specifies:

- Output types
- Output format
- Naming convention
- Output quality requirements

Implementation details are intentionally excluded.

---

# 2. Output Pipeline

```text
Transcript
      │
      ▼
Study Note
      │
      ▼
Knowledge Assets
      │
      ▼
Export
```

---

# 3. Output Assets

| Asset | Description |
|---------|-------------|
| Transcript | Original transcript |
| Study Note | Structured learning notes |
| Knowledge Card | Reusable knowledge summary |
| SOP | Standard operating procedure |
| Prompt | Reusable AI prompt |
| Skills | AI workflow skills |
| Export | Final deliverables |

# 5. Naming Convention

Standard Format

```text
{Title}_{VideoID}.md
```

Examples

```text
Claude_Code_ABC123.md

Study_Note_ABC123.md

Knowledge_Card_ABC123.md
```

---

# 6. Output Quality

Every output should be:

- Complete
- Consistent
- Structured
- Readable
- Reusable

---

# 7. Output Rules

- Generate one asset per document.
- Use UTF-8 encoding.
- Preserve source information.
- Keep document structure consistent.
- Do not overwrite existing outputs.
