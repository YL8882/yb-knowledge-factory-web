# Beta Feedback

## Purpose

This document records observations, usability feedback, bugs, and improvement ideas discovered during real-world use of the YB Knowledge Factory MVP.

The objective is to identify practical issues through daily usage before the first public release.

---

# Beta Testing Principles

- Use the product in real workflows.
- Record issues immediately after they occur.
- Focus on user experience rather than adding new features.
- Prioritize fixes based on actual usage frequency.
- Avoid implementing new features unless they solve repeatedly observed problems.

---

# Feedback Priority

| Priority | Description | Action |
|----------|-------------|--------|
| Critical | Prevents the product from working | Fix immediately |
| High | Significantly affects usability | Schedule for next update |
| Medium | Causes inconvenience but has a workaround | Evaluate after Beta |
| Low | Nice-to-have improvement | Consider for future versions |
