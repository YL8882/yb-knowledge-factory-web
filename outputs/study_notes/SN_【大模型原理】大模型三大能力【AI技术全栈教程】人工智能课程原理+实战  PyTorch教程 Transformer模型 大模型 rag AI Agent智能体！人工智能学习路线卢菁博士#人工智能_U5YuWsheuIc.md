## Executive Summary

本影片介紹大型語言模型（LLM）的核心能力、主要限制及其增強技術。LLM在語言理解上表現優異，但在推理與知識方面存在不足。為此，影片闡述了思維鏈（Chain-of-Thought）與RAG（Retrieval-Augmented Generation）等技術如何彌補這些缺陷，並透過提示詞工程的底層原理，解釋如何有效激發模型的潛能。

## Key Takeaways

*   LLM的固有優勢在於語言能力，能生成符合語法規範的內容。
*   LLM的主要弱點是推理能力不足及知識儲備有限（易產生幻覺、無法更新新知識）。
*   思維鏈（Chain-of-Thought）技術用於激發LLM的推理能力。
*   RAG（Retrieval-Augmented Generation）技術用於解決LLM的知識儲備問題及幻覺問題。
*   提示詞工程（Prompt Engineering）是與LLM互動的核心方式，透過提示詞激活和引導模型回應。
*   LLM被比喻為「大腦」，需要「手腳」或「工具」來協同完成複雜任務。

## Detailed Notes

### 大型語言模型 (LLM) 的能力與限制
*   **語言能力優勢：**
    *   LLM在語言理解與生成方面表現良好，輸出內容通常符合語法規範。
*   **主要能力不足：**
    *   **推理能力 (Reasoning Capability)：** LLM在複雜邏輯推理方面存在不足。
    *   **知識能力 (Knowledge Capability)：**
        *   模型知識儲備有其限制，無法即時更新新資訊。
        *   易產生幻覺 (hallucination)，給出看似合理但實際上不正確的答案。

### 增強 LLM 能力的技術
為了解決LLM在推理與知識方面的不足，發展出多種外掛技術：
*   **思維鏈 (Chain-of-Thought)：**
    *   主要目的：激發和增強LLM的推理能力。
    *   運用方式：引導模型逐步思考，分解問題，從而提升複雜推理的準確性。
*   **RAG (Retrieval-Augmented Generation)：**
    *   主要目的：解決LLM的知識儲備問題（如新知識、時效性知識）及幻覺問題。
    *   運用方式：透過外部知識庫檢索相關資訊，再將檢索結果結合提示詞輸入LLM，讓模型根據最新、最準確的資訊生成回答。

### 提示詞工程 (Prompt Engineering) 的底層原理
*   **核心功能：** 透過提供特定的提示詞 (Prompt) 來激發和引導大型模型的能力。
*   **底層邏輯範例 (以類比推理為例)：**
    1.  **輸入提示詞：** 例如「巴黎對法國，華盛頓對美國，北京對？」
    2.  **「燈神」處理：** 模型會透過「燈神」（可以理解為Embedding或向量化技術）將輸入的詞對（如「巴黎對法國」）轉換為可計算的數值表示（一對對的向量）。
    3.  **「FFM」提取特徵：** 透過「FFM」（Feature Fusion Module，影片中描述為特徵提取機制），模型從這些詞對中提取出核心特徵，例如「首都」這個資訊。
    4.  **特徵傳遞與預測：** 當遇到「北京」這個詞時，模型會將其與先前提取的「首都」特徵結合，進而在內部進行比對與推斷，最終預測出「中國」。
    5.  **總結：** 提示詞的本質是透過精心設計的輸入，將核心資訊與欲提問的問題連結，從而激發模型內部的知識與推理模式。

### LLM 與工具的協同作用
*   **LLM 類似「大腦」：** LLM本身擁有強大的語言理解與生成能力，如同一個「腦子」。
*   **需要「手腳」/「工具」：** 然而，單純依賴LLM無法處理複雜的業務或執行實際任務。它需要配合外部工具（例如：API、資料庫、其他特定模型），這些工具如同人類的「手腳」，才能將複雜的任務分解並逐步完成。
*   **協同關係：** LLM作為核心決策與理解者，結合外部工具才能發揮完整的應用價值，完成現實世界中的複雜工作。

## Core Concepts

*   **大型語言模型 (Large Language Model, LLM)：** 具備強大語言理解與生成能力的AI模型。
*   **推理能力 (Reasoning Capability)：** 處理邏輯問題、進行判斷和推導的能力。
*   **知識能力 (Knowledge Capability)：** 儲存、獲取和運用事實資訊的能力。
*   **思維鏈 (Chain-of-Thought, CoT)：** 一種提示技巧，引導LLM生成中間推理步驟，以提高複雜任務的表現。
*   **RAG (Retrieval-Augmented Generation)：** 檢索增強生成，結合檢索系統從外部知識庫獲取資訊，再由LLM生成回答的技術。
*   **提示詞工程 (Prompt Engineering)：** 設計和優化輸入給LLM的提示詞，以獲得期望輸出的技術與藝術。
*   **Embedding (向量化)：** 將文字或其他資料轉換為數值向量的技術，使機器可以理解和處理。影片中稱之為「燈神」。
*   **Feature Fusion Module (FFM)：** 影片中描述為從Embedding中提取並融合關鍵特徵的機制。

## Workflow

### 提示詞工程的推理範例流程
*   **Step 1: 構建類比提示詞**
    *   輸入：明確的類比對（例如「巴黎對法國」，「華盛頓對美國」），後接待推測的詞（「北京對？」）。
*   **Step 2: 透過「燈神」進行向量化**
    *   模型內部機制（「燈神」）將輸入的每一組詞（如「巴黎對法國」）轉換為數值表示（Embedding或向量）。
*   **Step 3: 透過「FFM」提取核心特徵**
    *   模型透過「FFM」機制從這些向量化的詞對中，識別並提取出共同的「首都對應國家」這種抽象關係或特徵。
*   **Step 4: 應用特徵進行推測**
    *   將提取出的「首都對應國家」特徵應用到待推測的詞「北京」上。
*   **Step 5: 生成最終預測**
    *   模型根據以上資訊進行判斷，最終預測出「中國」。

## Tools

    *   **Chain-of-Thought (思維練)**：一種用於提升推理能力的技術。
    *   **RAG (Retrieval-Augmented Generation)**：一種用於解決知識問題和幻覺的技術。
    *   **Prompt Engineering (提示詞工程)**：與LLM互動的核心技術。
    *   **外部工具/API**：泛指與LLM協同工作的任何外部系統或介面，以完成複雜任務。

## Best Practices

*   **彌補LLM弱點：** 針對LLM在推理能力和知識方面不足，應積極運用Chain-of-Thought和RAG等技術進行彌補。
*   **善用提示詞工程：** 透過精確設計提示詞，激發LLM的潛在能力，引導其給出符合預期的回答。
*   **結合外部工具：** 視LLM為核心「大腦」，搭配適當的外部「手腳」（如API、資料庫），使其能夠執行更複雜、更實用的任務。
